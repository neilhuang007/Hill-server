# World asset credits

## Authentication lobby

The server needs no third-party lobby: without a map in
`world-templates/hill_auth/` it builds its own plain lobby. Earlier smoke tests
used **Small Medieval Church 1.0.5**, by **CoinCoffer and TheHyperboloid**
([creator project](https://www.curseforge.com/minecraft/worlds/small-medieval-church)).
That map is All Rights Reserved, permission for the event is still pending, and
its creator's file listing has since been withdrawn. The installer no longer
downloads it, and it is not redistributed in GitHub or the owner asset packet.
Install only a lobby map the school is permitted to use.

## Exhibition hub

**Hill 175 Exhibition Hub 2026-08-26**, supplied by the Hill project owner.
The hub is delivered separately from Git as a world-save folder for
`world-templates/hill_hub/`, with its arrival point and guide positions in
`hill-world.yml`. It excludes player-save directories and source entities;
the plugin supplies the category personnel.

## People campus

The school-authorized campus is reconstructed at two blocks per metre using
measured terrain/building inputs and campus references. The current handoff is
**V29**, an unfinished floating exterior draft. Its tree trunk/branch generation
uses [DailyStruggle/leaf-treegen](https://github.com/DailyStruggle/leaf-treegen),
commit `d6b557ce4c5fdb4c3aed89bca8962f8dc62e592f`, copyright 2026 Leaf26,
under the [MIT license](leaf-treegen-LICENSE.txt). Campus-specific foliage,
planting, furniture and fantasy rock undersides are authored for this project.

Earlier terrain/building processing used
[VoxelEarth](https://github.com/ryanhlewis/VoxelEarth),
[Roofer](https://github.com/3DBAG/roofer), and
[VoxCity](https://github.com/kunifujiwara/VoxCity), alongside school and public
geographic reference material. Construction working notes and provenance source
files are preserved separately from the deployment branch.

The campus is supplied as region data with bounds/spawn metadata, excluding
player account files. Operators choose the template by installing its folder;
existing participants' worlds are not replaced by a new template.
[Installation and behavior](../CAMPUS_TEMPLATE.md).

Original project resource packs are stored under `server-assets/`. The V29 asphalt
pack is supplied in the asset handoff for optional Java client use. These packs
do not include a Bedrock conversion or automatic hosting/delivery.

Journey and Place worlds are generated by the Hill175 plugin. Pinned third-party
survival datapack sources and license identifiers are recorded in
[`survival-worldgen-manifest.tsv`](../../server-assets/survival-worldgen-manifest.tsv).
