# Campus v19 port for Minecraft Java 1.21.11

[Download the 1.21.11 world ZIP](../runtime/campus-reconstruction/exports/Hill-School-175th-v19-Java-1.21.11.zip) (9,018,267 bytes). Extract `Hill-School-175th-v19-1.21.11` into your 1.21.11 profile's `saves` folder. On Windows the default is `%APPDATA%\.minecraft\saves`. The world opens in Creative mode at the core spawn, block coordinates `[228,91,154]`; double-tap Space for flight.

On the project computer, run [Open-Hill-Campus-1.21.11.ps1](../Open-Hill-Campus-1.21.11.ps1), or double-click its [CMD wrapper](../Open-Hill-Campus-1.21.11.cmd). This opens the 1.21.11 client directly in the world and keeps a separate persistent Creative player save. The first run automatically stages missing official game assets; later runs reuse them. A live client test logged `HillBuilder joined the game` and showed a responsive `Minecraft 1.21.11 - Singleplayer` window. The versioned launcher requires this local project workspace, the prepared Python `uv` tool and the 1.21.11 client installation; the ZIP above is the portable world download.

This port comes from the frozen [v19 campus source](../runtime/campus-reconstruction/campus-context-v19-2x/world), whose 1.20.4 format predates the 26.1 storage change. A new isolated copy was fully converted, loaded and saved by the official Minecraft Java 1.21.11 server. The port uses DataVersion 4671 in `level.dat` and all **15,624** campus chunks. [Full parity audit](../runtime/campus-reconstruction/campus-port-1.21.11-v19b/block-parity-audit.json) compared every one of **1,535,901,696** block positions in those chunks and found zero state differences, zero missing/extra chunks and the same bell block entity. The 1.21.11 world retained Creative mode and the demonstration spawn. The [export report](../runtime/campus-reconstruction/exports/Hill-School-175th-v19-Java-1.21.11-export-report.json) records the ZIP and each archived file's SHA-256; ZIP CRC and equality checks passed.
