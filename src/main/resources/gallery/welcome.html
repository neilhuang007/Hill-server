Join the shared build with the server address and joining instructions from the event organizer.

A few tips for the shared campus

Leave other people’s work as you found it unless you’ve agreed on a change, and keep chat welcoming.

Use the map in hotbar slot 9, or type /campus, to find a building. The Undo item in slot 8 can help with a recent mistake. If something bigger goes wrong, tell a staff member where it happened.

Follow the login instructions you’re given, and keep your password and verification codes private. If you need a hand joining, ask the event organizer.
