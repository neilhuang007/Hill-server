How to join on Java

  1. Open Minecraft, choose Multiplayer, then Add Server.

  2. Name it The Hill. Paste java.thehill.org into Server Address, then choose Done.

  3. Select The Hill in your list and choose Join Server.

How to join on Bedrock

For Windows and mobile.

  1. Open Minecraft, choose Play, then Servers. Scroll down to Add Server.

  2. Name it The Hill. Enter bedrock.thehill.org as the address and keep port 19132.

  3. Choose Save, then select The Hill and join.
